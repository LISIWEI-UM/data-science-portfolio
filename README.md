GitHub Pages publishes the Jekyll site from the root of `main`. The home page is `index.md`. Project pages have explicit permalinks, share `_layouts/default.html`, and use local files in `assets/`. When results change, rerun the analysis and update the figures, captions and any numbers on the home page together.
